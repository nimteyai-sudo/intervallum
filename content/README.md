# Банк заданий

Задания взяты из открытого банка **ФИПИ**.

## Что внутри

- `fipi_physics_2026.json` — 1 145 заданий по физике.
- `media/ege_2026/` — картинки и графики к заданиям.

## Типы ответов

- число;
- выбор нескольких вариантов;
- код из цифр, например `11`, `22`, `333`;
- измерение, например `450,012,5`.

## Как добавить задания

```bash
python scripts/import_fipi.py \
  --pdf-dir "/путь/к/PDF" \
  --out content/fipi_physics_2026.json \
  --media-dir content/media/ege_2026
```

Импортёр проверяет ответы и не добавляет задание, если не может определить ответ.
