# Intervallum

**Адаптивный тренажёр по физике для подготовки к ЕГЭ.**

Проект сам подбирает следующее задание под ученика, проверяет ответы, показывает прогресс и помогает понять, к какому результату на экзамене человек идёт.

## Что уже работает

- Подбор заданий под уровень ученика.
- Проверка ответов разных типов.
- Повторение тем в нужный момент, чтобы знания не забывались.
- Объяснение, почему система выбрала именно это задание.
- Прогресс по темам и ошибкам.
- Прогноз диапазона баллов ЕГЭ.
- Учительские назначения и приоритет обязательных заданий.
- Docker-запуск одной командой.
- Симулятор ученика для проверки системы без реальных пользователей.

## Задания

В проекте **1 145 заданий по физике** из открытого банка **ФИПИ**.

Для 471 задания есть рисунки и графики. Они лежат в папке `content/media`.

## Быстрый запуск через Docker

```bash
cd intervallum
docker compose up --build
```

После запуска открыть:

```text
http://127.0.0.1:8000/docs
```

Там можно выбрать задание, проверить ответ и посмотреть прогноз.

Остановить:

```bash
docker compose down
```

## Запуск без Docker

```bash
cd intervallum
python3 -m venv .venv
. .venv/bin/activate

pip install -e ".[dev,api]"

pytest -q
uvicorn intervallum_ml.api:app --reload
```

Открыть:

```text
http://127.0.0.1:8000/docs
```

## Как пользоваться

1. Открыть `http://127.0.0.1:8000/docs`.
2. Выбрать `POST /v1/select` — система выдаст задание.
3. Отправить ответ в `POST /v1/grade` — система проверит.
4. Отправить попытку в `POST /v1/attempt` — обновится прогресс.
5. Открыть `POST /v1/readiness` — система покажет прогноз баллов.
